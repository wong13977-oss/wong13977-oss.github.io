How do I categorize a list of websites by IAB category, brand safety and parked status with an API?

Updated 2026-10-14 · By Wong Xian Qi

The IAB Tech Lab publishes its Content Taxonomy 3.1 for free on GitHub, but the file is only a list of categories and IDs: it does not say which category a given website belongs to. To label a domain list you have to read each site and pick a category, by hand or through an API that is not affiliated with IAB Tech Lab, such as the AI Website Categorization Actor, which returns the IAB Tier 1 and Tier 2 category with its ID, brand safety flags and a parked or dead status for every domain.

What is the IAB Content Taxonomy 3.1 and where do I get it?

It is IAB Tech Lab's tiered list of content categories, each with a unique ID. The tab-separated file is in the IAB Tech Lab Taxonomies repository on GitHub, licensed under Creative Commons Attribution 3.0. The Actor uses Tier 1 and Tier 2, which are 37 and 323 categories. Examples: ID 52 is Business and Finance, ID 596 is Technology & Computing, and the Sensitive Topics group uses alphanumeric IDs such as v9i3On. Version 3.1 has no general News category, which matters for publishers (see the limits below).

How can I look up a domain's IAB category by hand?

  1. Open the site and read its homepage and About page.
  2. Find the closest Tier 1 category in the taxonomy file, then its best Tier 2 child.
  3. Write down the ID, not only the name.

That works for a handful of domains. On a long list the effort goes into everything around the lookup: redirects, parked domains, sites that block automated visitors and robots.txt rules that forbid reading a site.

How does the API categorize a domain?

  • It checks robots.txt before every page it reads, for its WebsiteCategorizationBot user agent and the * group. A robots.txt that answers with a server error (5xx) counts as "disallow all", as RFC 9309 says.
  • It reads the homepage, the About page if one is linked and, with maxPagesPerDomain set to 3, one products or services page (default 2).
  • It sends the title, meta description, headings, structured data types and visible text to an OpenAI model together with the full taxonomy. The model must choose a category from the list; the Actor maps it to the official ID and validates it.
  • Brand safety covers the 11 IAB Sensitive Topics plus gambling. The model's flags are topped up by the IAB category itself and by keywords in page titles and descriptions, and brandSafetyRisk (none, low, medium, high) is the highest severity found.

If a site blocks automated visitors, disallows them in robots.txt or drops the connection, the optional AI knowledge fallback (on by default) asks the model what it knows about that exact domain without visiting the site again. Those results carry classificationSource: "ai_knowledge" and a confidence capped at 0.8. Parked and non-existent domains are never classified this way.

How do I find parked domains in a list?

Every domain gets a status: ok, redirect, parked, unreachable, robots_disallowed or blocked. A domain is parked when it uses parking nameservers, lands on a domain marketplace such as Sedo, Dan or Afternic, or shows a for-sale page, a default server page or a "coming soon" placeholder. statusReason explains it, for example "Domain uses parking nameservers (afternic.com)". By hand you would check each domain's nameservers and open each site.

What does it not cover?

  • Tier 1 and Tier 2 only. The file's Tier 3 and Tier 4 rows are not returned.
  • One category per site, judged on its main purpose. It is not a classifier for single articles.
  • Only the homepage, About page and at most one more page are read. Sites that need JavaScript to show text may come back as unreachable.
  • General news publishers and government portals are labelled Politics unless another topic clearly dominates; the industry field can still say "News / Broadcasting".
  • Bot protection is never bypassed and CAPTCHAs are never solved. Those sites are blocked unless the fallback can classify them.
  • www.example.com and example.com are checked as separate domains.
  • Accuracy: in the developer's own tests on more than 150 well-known websites, about 97% got a sensible IAB category (the misses were close calls) and the language was always right. This is not an independent benchmark.

FAQ

Is there a free API to get the IAB category of a website?

The IAB Tech Lab Content Taxonomy 3.1 file is free on GitHub, but it only lists categories and IDs, not which category a site belongs to. The AI Website Categorization Actor does the classification through the Apify API for $0.006 per classified domain, and Apify's free plan includes monthly platform credit that its README says is enough to try it on hundreds of domains.

Which IAB Content Taxonomy version does it use, and is it an official IAB tool?

It uses IAB Tech Lab Content Taxonomy 3.1, Tier 1 and Tier 2 (37 and 323 categories) with the official IAB IDs. It is not affiliated with or endorsed by IAB Tech Lab.

How do I find parked or for-sale domains in a list?

Run the list and filter the results on status = parked. The Actor marks domains that use parking nameservers, redirect to a domain marketplace, show a for-sale page, a default server page or a coming-soon placeholder. Parked domains cost $0.001 each instead of $0.006.

How accurate is the IAB category?

In the developer's own tests on more than 150 well-known websites, about 97% got a sensible IAB category and the misses were close calls. Borderline sites can change category between runs, so filter on status = ok and a confidence of 0.7 or more when you need high certainty.

Does it respect robots.txt?

Yes. It checks robots.txt for its WebsiteCategorizationBot user agent and the * group before every page, reads at most 3 public pages per domain, never logs in and never solves CAPTCHAs or works around bot protection.

Can it classify websites that block automated visitors?

Optionally. With the AI knowledge fallback on, a blocked, robots.txt-disallowed or unreachable site is classified from the AI model's own knowledge of that domain, without visiting it again. These results are marked ai_knowledge and capped at 0.8 confidence; unknown domains stay unclassified and cost $0.001.
