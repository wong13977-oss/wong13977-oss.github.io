Is there an airline baggage allowance API? Carry-on and checked bag limits by airline and fare, as JSON

Updated 2026-10-14 · By Wong Xian Qi

The authoritative source for baggage rules is each airline's own baggage pages. The Airline Baggage Allowance API, an Apify Actor, reads those official pages every week and returns the rules as JSON, one record per fare: carry-on size and weight, personal item, checked baggage and special items. Coverage is narrow on purpose: it includes only Air Arabia, Malaysia Airlines, Thai Airways and Vietnam Airlines (60 fares in total).

Where do airline baggage rules officially come from?

From the airline's website. The official pages for the four covered airlines are Malaysia Airlines cabin baggage, Thai Airways carry-on baggage, Vietnam Airlines hand baggage and Air Arabia hand baggage. Rules can differ by route, date and booking, so confirm with the airline before you travel.

Why is comparing baggage rules by hand slow?

  • Airlines describe carry-on and checked rules differently: per fare bundle, per route, in tables, pop-ups and footnotes. The rules also change without notice.
  • Units and concepts differ: kilograms, centimetres, linear size limits and piece versus weight concept for checked bags.
  • Details sit in notes. Malaysia Airlines' 7 kg cabin limit is shared with the personal item, and Air Arabia's cabin allowance includes duty-free purchases.

What is the Malaysia Airlines baggage allowance by fare?

All six Malaysia Airlines economy records in the same run show one carry-on piece of up to 7 kg. The checked allowance varies by fare and route:

  • Economy Value, Economy Basic and Economy Flex/Shuttle (all routes except Malaysia-Japan, Jeddah, Madinah and AMAL flights): 20 kg, 25 kg and 35 kg.
  • Economy Group: 20 kg on domestic Malaysia routes, 30 kg international.
  • Economy Class on international Piece Concept routes: 2 pieces of up to 23 kg.

The ready-made run Get Malaysia Airlines baggage allowance by fare returns every Malaysia Airlines fare, not only economy.

How do you get baggage rules as JSON?

Pass IATA codes or names in airlines (empty means every covered airline), optionally a cabinClass (economy, premium, business or first), and choose whether to include strollers, instruments and sports equipment with includeSpecialItems. Each record has carryOn, personalItem and checked blocks, a confidence of high, medium or low, source links and verification dates. A value is null when the airline's page does not state it. An AI model turns the page text into these fields, and every number must appear on the airline's page. One record from the run above (fields trimmed, special items off):

Can it alert you when baggage rules change?

Yes. Set onlyChangedSince to a date such as 2026-10-01 or a period such as 7 days and schedule the run weekly. You get only the fares whose rules changed, with lastChanged and a changeSummary such as "Carry-on max weight: 7 kg → 10 kg". Fares an airline removed in that period are listed in the run summary at no charge.

How much does the baggage allowance API cost?

  • $0.02 per fare returned (a "Baggage rule" result).
  • $0.05 per changed fare when you use onlyChangedSince (a "Change alert", charged instead of the normal result).
  • A start fee of $0.00005 per run and no charge for compute time.

Malaysia Airlines' 10 fares cost $0.20, and every covered airline (60 fares) about $1.20. The 26-record economy carry-on comparison across all four airlines would cost about $0.52. A weekly change check where nothing changed costs $0.00005. Apify Bronze, Silver and Gold subscribers get lower prices. maxResults is a hard cap on spend.

Which airlines are covered, and what is missing?

  • Four airlines only: Air Arabia (G9), Malaysia Airlines (MH), Thai Airways (TG) and Vietnam Airlines (VN). Other airlines you request are listed in the run status and cost nothing. Vueling is paused because its website does not answer requests from the Apify platform.
  • Why not more: the Actor reads only airline websites whose terms and robots.txt allow automated access, and many large airlines block automated reading. You can ask for an airline in the Actor's Issues tab.
  • Known gaps: Vietnam Airlines carry-on fields are empty, and for some fares the airline's pages do not state every value.
  • Fees: checked.feeNotes summarizes what the pages say, but live prices for extra bags are not included.
  • Weekly, not real time: check lastVerifiedAt, and confirm with the airline before you travel.

FAQ

Is there an API for airline baggage allowance and carry-on limits?

For a small set of airlines, yes. The Airline Baggage Allowance API on Apify returns carry-on, personal item and checked bag rules per fare as JSON for Air Arabia, Malaysia Airlines, Thai Airways and Vietnam Airlines, taken from their official baggage pages. It does not cover other airlines.

What is the Malaysia Airlines carry-on limit in economy?

In the Actor's data extracted on 13 October 2026, it is one piece up to 7 kg and 56 x 36 x 23 cm (115 cm linear), and the personal item counts towards the same 7 kg. Confirm on the airline's page, because rules can differ by route, date and booking.

How often do airline baggage rules change?

Airlines change them without notice, so the Actor re-checks each covered airline's pages every week and records the date (lastChanged) and a summary of each change. Airlines that could not be checked for over two weeks are listed in the run summary.

Does the API include baggage fees?

Partly. The checked.feeNotes field summarizes what the airline's pages say about paid and extra bags, but live prices for extra bags depend on route, date and booking channel and are not included.

Why isn't my airline covered?

The Actor reads only airline websites whose terms and robots.txt allow automated access, and it identifies itself honestly instead of pretending to be a browser. Many large airlines block automated reading, so they are not covered; you can request an airline in the Actor's Issues tab.

Is it legal to use airline baggage data?

The Actor reads only public baggage pages from the airlines' official websites, respects robots.txt and each site's terms, and reads each page once a week. It does not collect any personal data.
