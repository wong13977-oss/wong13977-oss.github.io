Use visa sponsor, school holiday, halal certificate, HS code and other data tools in Claude, ChatGPT and Cursor (MCP)

Updated 2026-10-17 · By Wong Xian Qi

To give Claude, ChatGPT, Cursor or another MCP client access to these data tools, add one remote MCP server URL and sign in with a free Apify account. The assistant then gets ten tools: tech conference CFPs, school term dates, visa sponsor registers, halal certificates, airline baggage rules, HS codes, Southeast Asian marketplace listing translation, website categorization, mobile plan prices and recipes from cooking videos. Each tool charges per result returned, billed to your own Apify account.

What is the MCP server URL?

The server is Apify's hosted MCP server, limited to these ten tools plus two helper tools for fetching results of longer runs. It uses the Streamable HTTP transport and OAuth sign-in:

https://mcp.apify.com/?tools=messnomore/cfp-radar,messnomore/school-holidays-api,messnomore/visa-sponsor-checker,messnomore/halal-certificate-checker,messnomore/airline-baggage-allowance,messnomore/hs-code-classifier,messnomore/sea-listing-localizer,messnomore/website-categorization,messnomore/mobile-plans-tracker,messnomore/video-to-recipe,get-actor-run,get-dataset-items

How do I connect it to Claude?

  1. In Claude (claude.ai or Claude Desktop), open Settings and then Connectors.
  2. Select Add, then Add custom connector.
  3. Enter a name such as MessNoMore data tools and paste the URL above as the remote MCP server URL.
  4. Select Continue, keep the detected OAuth settings and select Add. Your browser opens to sign in to Apify.

In Claude Code, run:

claude mcp add --transport http messnomore "https://mcp.apify.com/?tools=messnomore/cfp-radar,messnomore/school-holidays-api,messnomore/visa-sponsor-checker,messnomore/halal-certificate-checker,messnomore/airline-baggage-allowance,messnomore/hs-code-classifier,messnomore/sea-listing-localizer,messnomore/website-categorization,messnomore/mobile-plans-tracker,messnomore/video-to-recipe,get-actor-run,get-dataset-items"

How do I connect it to ChatGPT?

  1. Turn on Developer mode in ChatGPT.
  2. Go to Settings, Apps & Connectors, Create.
  3. Paste the URL above as the MCP server URL and choose OAuth as the authentication.
  4. Select Create and authorize ChatGPT in the Apify sign-in page.

ChatGPT does not let you change the tool list of a connector after it is created; create a new connector to change it.

How do I connect it to Cursor, VS Code or other clients?

Most clients accept a remote server entry with a URL. Cursor (mcp.json):

{
  "mcpServers": {
    "messnomore": {
      "url": "https://mcp.apify.com/?tools=messnomore/cfp-radar,messnomore/school-holidays-api,messnomore/visa-sponsor-checker,messnomore/halal-certificate-checker,messnomore/airline-baggage-allowance,messnomore/hs-code-classifier,messnomore/sea-listing-localizer,messnomore/website-categorization,messnomore/mobile-plans-tracker,messnomore/video-to-recipe,get-actor-run,get-dataset-items"
    }
  }
}

If a client cannot do OAuth, send your Apify API token as an Authorization: Bearer YOUR_APIFY_TOKEN header instead.

Is there an agent skill for these tools?

Yes. The free Data Tools Pack skill on Agensi is a SKILL.md for Claude Code, Cursor, Codex and other agents that support skills. Install it next to the MCP server: the skill holds the instructions and the server runs the lookups. The skill tells the agent:

  • which of the ten tools fits the question, and which arguments to pass;
  • to cap each run to the results the question needs, and to ask before any run likely to cost more than about $1;
  • how to wait for long runs with get-actor-run without starting a duplicate;
  • to answer with source links and last-verified dates, and never to fill gaps from memory.

Single-tool skills, for when you only need one of the tools, are listed on the creator page. The skills are free; lookups are billed per result to your Apify account as above.

FAQ

Is there an MCP server for UK visa sponsors, school term dates or halal certificates?

Yes. Add the remote MCP URL on this page to Claude, ChatGPT, Cursor or any MCP client and the assistant gets ten tools, including a visa sponsor checker, a school term dates API and a halal certificate checker.

Do I need an account?

Yes, a free Apify account. The tools run on Apify, and the first connection opens an Apify sign-in page to authorize your MCP client.

How much does it cost?

There is no subscription. Each tool charges per result returned, from $0.002 per visa sponsor record to $0.04 per recipe (Mobile Plans Tracker also charges $0.05 per carrier), billed to your Apify account. Apify's free plan includes monthly usage credit.

What happens if a lookup takes longer than the assistant waits?

The server includes the get-actor-run and get-dataset-items tools, so the assistant can check the run and fetch the results once it finishes.

Are these official government or registry tools?

No. They are independent tools that read official public sources such as the UK register of licensed sponsors, council and state school calendars, the JAKIM and BPJPH registries, and mobile carriers' plan pages. Confirm important results with the official source.

Is there a Claude Code or Cursor skill for these tools?

Yes. The free Data Tools Pack skill on Agensi is a SKILL.md that tells Claude Code, Cursor, Codex and other agents which tool fits a question, caps each run and asks before any run likely to cost more than about $1. It works together with this MCP server.
